# EvasionFromICL
## data File contains origianl data and final test.csv with train.csv after processing.
## data_preprocessing.ipynb contains the code to process the original data.
## Imperceptible Perturbations.ipynb is used to generate Bad Characters attack.
## traditional_blackbox_evasion_attacks.ipynb contains the code to train and evaluate the Bert Model. Further more, it accomplished TextFooler, DeepWordBug and TextBugger attacks.
## blackbox_adv_examples_against_ICL_with_LLMs_defense.ipynb contains our main code to construct the ICL-based text classifiers,evaluate the performance of ICL, and  construct the attack and defense strategy.
## Visualization.ipynb helps visualize the final json results.
