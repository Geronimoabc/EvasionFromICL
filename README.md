# ICL-Evader
This is the official repository for our research paper titled as "**ICL-Evader: Zero-Query Black-Box Evasion Attacks on In-Context Learning and Their Defenses**" accepted at **the ACM Web Conference 2026 (WWW '26)**. **DOI**:[ICL-Evader](https://doi.org/10.1145/3774904.3792344).

## File instrutions
1. original_data file contains origianl data without processing, final_data file contains test.csv and train.csv after processing.
2. data_preprocessing.ipynb contains the code to process the original data.
3. blackbox_adv_examples_against_ICL_with_LLMs_defense.ipynb contains our main code to construct the ICL-based text classifiers, evaluate the performance of ICL, and construct the attack and defense strategy.
